# buyung.io — 3D Agent Office

A locally generated Three.js office campus for buyung.io.

## Run

From this directory: `python3 -m http.server 4173 --directory dist`, then open http://localhost:4173.

No build or package install is needed. Three.js 0.160.0 and OrbitControls are vendored in `dist/vendor`. Models, furniture, characters, terrain and textures are generated by `dist/app.js`.

## Controls

- Left/middle drag: pan. Right drag: orbit. Wheel: zoom.
- Touch: one finger to pan; two fingers to zoom and rotate.
- Arrow keys: pan. Toolbar: zoom, rotate, reset.
- Room buttons: smooth camera focus. Agent labels: details.
- Demo: all eleven agents switch to working states and animated gestures.

The displayed metrics and agent activity are sample data, not a connection to the reference site's live infrastructure.

## Mushalla

Buyung (CEO) leads a two-rakaat prayer, with Muhammad (COO) and Anggit (CTO) in a row behind him. Makmum motions begin 1.05 seconds after the imam. Jointed models perform takbir, folded-hand standing, flat-back rukuk, upright iktidal, two sujud per rakaat, iftirasy, final tawarruk, and right/left salam. The animation has quiet holds in every posture and does not change with office Demo mode.

Pose and sequence reference: https://tarjih.muhammadiyah.or.id/cara-duduk-tahiyat-pada-shalat-dua-rakaat . This is a stylized visual animation, not a recitation or instructional prayer timer.
